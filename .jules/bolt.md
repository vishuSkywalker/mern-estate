## 2026-04-09 - [Asynchronous bcryptjs for non-blocking event loop]\n**Learning:** In Node.js, synchronous methods like `bcryptjs.hashSync` and `bcryptjs.compareSync` block the event loop, severely degrading performance under load. This is a critical codebase-specific performance pattern.\n**Action:** Always use the asynchronous versions (`await bcryptjs.hash` and `await bcryptjs.compare`) in Express controllers to avoid blocking the Node.js event loop.
