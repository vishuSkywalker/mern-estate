## 2024-05-24 - Async vs Sync Cryptography in Node.js\n**Learning:** Node.js event loop blocks when using synchronous cryptography methods like `bcryptjs.hashSync` and `bcryptjs.compareSync`, which severely degrades concurrent request handling throughput.\n**Action:** Always use the async, promise-based versions (`await bcryptjs.hash`, `await bcryptjs.compare`) in Express controllers to ensure non-blocking IO behavior.
