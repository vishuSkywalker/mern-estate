## 2024-05-14 - [Synchronous Cryptography Blocking Node.js Event Loop]
**Learning:** Found synchronous `bcryptjs.hashSync` and `compareSync` calls in the critical path of the authentication controllers (`signup`, `signin`, `google`, and `updateUser`). Because Node.js is single-threaded, CPU-bound tasks like password hashing completely block the event loop. If multiple users attempt to sign in or sign up concurrently, these synchronous calls will queue up and stall all other requests to the server, resulting in terrible performance and potential timeouts.
**Action:** Always verify that cryptographic operations (hashing, signing, comparing) use asynchronous versions (`await bcryptjs.hash`, `await bcryptjs.compare`) in Express controllers to ensure the Node.js event loop remains unblocked.
